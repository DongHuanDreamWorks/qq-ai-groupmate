# 控制台使用说明

地址：`http://<host>:8088`
首次密码在 `data/console/initial_password.txt`，登录后可在页面右上角改。

页面顶部有一条告警横幅：QQ 掉线、心跳停止、模型失败率过高、磁盘不足都会在这里出现。

## 1. 概览

- 机器人在线状态、今日消息数、回复数、模型调用与花费。
- **QQ 离线时自动出现二维码卡片**：手机扫码即可重登；「重新生成二维码」会请求看门狗重启 NapCat。
- 最近事件时间线，方便快速看“刚才发生了什么”。

## 2. 对话调试

一个不经过 QQ 的模拟器。输入一句话，走完整的大脑流程（含工具调用），
用于调人设、测语气、试工具，不会发到群里。

## 3. 长期记忆

- 左侧是所有人的列表，按消息量排序。
- 右侧可编辑：显示名、一句话印象、风格、标签、事实、四个维度
  （熟悉度 / 好感度 / 活跃度 / 信任度）。
- 「重新提炼」让模型根据最近消息重写印象；「删除」会连同该用户消息一起清掉。
- 显示名优先级最高，用来处理“同一个人不同群名片”的情况。

## 4. 上下文

- 每个群的最新消息、摘要、上一次午夜归档的内容。
- 「从 QQ 拉取最近 50 条」用于补历史；「清空上下文」只删消息，不动长期记忆。
- 「立即归档」手动触发一次“总结 + 清空”。
- 底部是**人物动态**：每个人最近在关心什么、话题标签。
  聊天里提到某人的名字时，这份摘要会被自动带进上下文。

## 5. 人设

| 字段 | 作用 |
|---|---|
| 名字 / 身份 | 自称与一句话底色 |
| 系统提示词 | 核心，越短越像人；支持 `{name} {identity}` |
| 背景故事 | 没上下文时的谈资 |
| 常住城市 | 天气和本地新闻按它抓 |
| 生活碎片开关 / 时间 | 默认每天 12:00 |
| 生活碎片提示词 | 固定模板，模型不能改；占位符 `{name} {city} {date} {weather} {news}` |
| 当前生活碎片 | 每天被覆盖，也能手改 |
| 说话风格 / 禁忌 / AI 身份策略 | 语气与边界 |

底部「立即按今天刷新」会马上抓天气和新闻，生成新碎片。

## 6. 触发策略

- **分时段回复率**（JSON）：默认 12–20 点 100%，8–12 点 50%，20–24 点 25%，其余 0%。
- **合并回复**：窗口秒数、单条回复占比（默认 25% 单条 / 75% 合并）。
- 冷却秒数、每 10 分钟上限。
- 白名单群（留空 = 所有群）、是否回 @、是否回私聊、前缀、关键词、最短长度、防复读。

## 7. 主动发言

- 开关、最短/最长间隔（分钟）、群安静多久才开口、安静多久就不打扰。
- 免打扰时段、每天上限、目标群、唤醒提示词。
- 右侧能看到下一次唤醒时间和今天已发次数；「立即发一条」可以手动测试。

## 8. 自运营

- **资料**：昵称、签名。
- **头像**：填图片 URL 直接换；也可以让它用 `change_avatar` 自己画一个。
- **空间**：让模型起草、直接发、选可见范围；下面是历史说说，可删除。
- **每天自动发说说**：开关 + 时间 + 可见范围。

## 9. 外部 AI

工具的总开关和额度：

- 生图 provider、每天最多几张。
- `ask_ai` 允许的 provider（Pollinations / DeepSeek / Chatbox / OpenAI 兼容）与每小时、每天调用上限。
- 表情自动发送概率、空间工具开关等。

## 10. 表情

- **小黄脸映射**：`ID → 名称`，一行一个，模型输出 `[face:14]` 时据此还原。
- **表情收藏库**：从 QQ 云端同步的自定义表情，带 AI 描述和话题标签；
  可手动同步，模型用 `send_sticker` 按情绪挑。

## 11. 好友 / 入群

- 自动同意好友 / 入群邀请，验证词，通过后的招呼语。
- 白名单/黑名单；下方是所有申请记录。
- 新号建议先关着，很容易触发风控。

## 12. 模型

- Base URL、API Key、模型名、温度、最大 token、是否开启视觉。
- 「测试」按钮会发一句话，返回耗时、token 和估算费用。
- 也可以在这里看到 `brain_token`（AstrBot 插件需要）。

## 13. 日志

- 事件日志（info / warn / error）与最近的模型调用记录。
- 底部有导出 / 导入备份。导入会**覆盖**现有数据，慎用。
